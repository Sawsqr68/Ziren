# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

**⚠️ Please do NOT open a public issue for security vulnerabilities.**

### How to Report

1. Email: security@zkm.io (or appropriate security contact)
2. Use PGP encryption for sensitive reports: [Contact us for PGP key]
3. Expected response time: 48 hours

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response SLA

- **Critical**: 24 hours
- **High**: 72 hours
- **Medium**: 1 week
- **Low**: 1 month

## Security Best Practices

This project uses:
- Modified cryptographic libraries - see [SECURITY_AUDIT.md](SECURITY_AUDIT.md)
- Git dependencies - requires careful review
- Zero-knowledge proof systems - requires expertise

## Acknowledgments

We appreciate responsible disclosure and will acknowledge security researchers who help improve the security of this project.
